## Important point

- In `RStudio`, please set your working directory the the base of where you donwloaded this repository/zipped file to. You will need to set this to access the files without the need to provide the full file path every time. You can set the working directory using the `setwd()` function.

- E.g., `setwd('/Users/jogrady/Downloads/EU-LI-PHE_Workshop-main/EU-LI-PHE_Workshop-main/')`

- Then in the file explorer. Click `More` and then click `Go To Working Directory`.
